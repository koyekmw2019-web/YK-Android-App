# YK Android App

Android WebView app for the YE KUN official website.

- App name: **YK**
- Package: `com.yekun.yk`
- Icon: black background with white **YK**
- The app opens the official website inside the app and sends external links to the appropriate browser/app.
- GitHub Actions builds an installable debug APK automatically.

## APK
Open **Actions → Build YK APK → latest successful run → Artifacts → YK-APK**.
